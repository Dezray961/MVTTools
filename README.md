# Installation Guide
1. Set up a virtual environment using `conda` or `pyenv`
2. Download NASA's High Energy Astrophysics software (HEASoft) package. This can be done manually [here](https://heasarc.gsfc.nasa.gov/docs/software/lheasoft/) or there is an [automated installer](https://github.com/XRByte/HEAinstaller) provided by [Anish Sarker](https://github.com/XRByte).
>### Note
>It is **your** responsibility to check that both this package and the automatic HEASoft installer are safe to use!
3. Clone this repo to the folder that you want to install it in.
```
git clone https://github.com/Dezray961/MVTTools
```
4. Navigate to the directory and run
```
pip install -r requirements.txt
```
